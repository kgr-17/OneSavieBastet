# Codex ↔ Claude Code Bridge

A single-file, zero-dependency coordination layer so **Codex** and **Claude Code** can collaborate inside any shared repository.

No API calls. No servers. Just files in your repo.

---

## How it works

```
Codex creates a task  →  writes  bridges/claude-code/tasks/<id>.json + .md
Claude reads the task →  claims, works, writes  bridges/claude-code/responses/<id>.json + .md
Codex reads response  →  integrates, closes task
```

Both agents see the same files. The bridge is pure coordination metadata — no hidden state.

---

## Setup (one time per project)

Copy `claude_bridge.py` into your project (or anywhere on your PATH), then run:

```bash
python claude_bridge.py install
```

This creates the `bridges/` directory tree and writes a `CLAUDE.md` at your project root that tells Claude Code how to use the bridge automatically.

To install into a specific folder:

```bash
python claude_bridge.py install --project-root /path/to/myproject
```

## Codex workflow

```bash
# 1. Create a task for Claude Code
python claude_bridge.py create-task \
  --title "Add retry logic to the scraper" \
  --request "Add exponential backoff to fetch_page() in src/scraper.py. Max 3 retries." \
  --path "src/scraper.py" \
  --constraint "Do not change the function signature."

# 2. (Optional) Preview the prompt Claude Code will see
python claude_bridge.py render-prompt --task-id <task-id>

# 3. Wait — Claude Code will write a response file

# 4. Read the response
python claude_bridge.py list
python claude_bridge.py show --task-id <task-id>

# 5. After integrating the result, close the task
python claude_bridge.py close --task-id <task-id> --resolution "Merged, tests pass."
```

---

## Claude Code workflow

```bash
# 1. See open tasks
python claude_bridge.py list --status open

# 2. Claim a task (signals you're working on it)
python claude_bridge.py claim --task-id <task-id> --agent claude-code

# 3. Do the work in the repo...

# 4. Write your response
python claude_bridge.py respond \
  --task-id <task-id> \
  --agent claude-code \
  --summary "Added exponential backoff with jitter in fetch_page(). Max 3 retries, base delay 1s." \
  --file-touched "src/scraper.py" \
  --next-step "Run the test suite to confirm no regressions."
```

## Command reference

| Command | Who uses it | What it does |
|---------|-------------|--------------|
| `install` | Either | Scaffold bridge dirs + write CLAUDE.md |
| `create-task` | Codex | Create a new work request for Claude Code |
| `list` | Either | List tasks (filter by `--status`, `--assignee`) |
| `show` | Either | Print a task as JSON |
| `claim` | Claude | Mark a task as in-progress |
| `respond` | Claude | Write a response (summary, files, questions) |
| `close` | Codex | Close a task after integrating the result |
| `render-prompt` | Codex | Print a task as a Claude-friendly prompt |

---

## Task lifecycle

```
open → claimed → answered / blocked / needs-review → closed
```

- **answered**: Claude finished. Codex should review and close.
- **blocked**: Claude needs more info. Check `questions` in the response.
- **needs-review**: Claude made changes but wants Codex to verify before closing.

---

## Tips

**Scope tasks tightly.** One task = one bounded change in a small set of files. Vague tasks produce vague responses.

**Use `--constraint` to set guard-rails.** E.g. `--constraint "Do not change public API"` or `--constraint "Python 3.9 compatible only"`.

**Use `--path` to point at the right files.** Both agents open the same repo — the path list tells Claude exactly where to look.

**Tasks are just files.** If the CLI is inconvenient, you can write/edit the JSON directly under `bridges/claude-code/tasks/`. The Markdown file is auto-generated from JSON.

**Bridge root is configurable.** Use `--bridge-root` if you need a non-default location:
```bash
python claude_bridge.py --bridge-root .collab/bridge list
```

## File structure

```
bridges/
  claude-code/
    tasks/
      20260408-120000-add-retry-logic.json   ← task data
      20260408-120000-add-retry-logic.md     ← human-readable version
    responses/
      20260408-120000-add-retry-logic--claude-code--20260408-130000.json
      20260408-120000-add-retry-logic--claude-code--20260408-130000.md
    archive/                                 ← reserved for cleanup scripts
CLAUDE.md                                    ← auto-generated by `install`
claude_bridge.py                             ← this script
```
