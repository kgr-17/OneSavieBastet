**Terms**
`P` = precision. Of the things the agent predicted, how many were correct.  
Formula: `matched / predicted`.

`R` = recall. Of the things that were truly present, how many the agent found.  
Formula: `matched / truth`.

`F1` = harmonic mean of precision and recall. It balances “don’t overpredict” and “don’t miss things.”  
Formula: `2PR / (P + R)`.

`predicted_row_count` = raw number of emitted holdout predictions.

`predicted_count` = deduplicated evaluation signatures after collapsing rows into the scorer’s comparison key.

`truth_count` = number of ground-truth evaluation signatures on the holdout side.

`matched_count` = number of predicted signatures that matched the normalized truth.

`repo+severity+tag` = strict local metric. A prediction only matches if repo, severity, and tag all line up.

`repo+tag` = looser family metric. A prediction matches if repo and tag line up, even if severity differs.
